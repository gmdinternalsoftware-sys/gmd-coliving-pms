# GMD Co-living PMS — Maintenance Team One-Page User Guide

**Role:** Maintenance Staff (`maintenance`)  
**Scope:** View and track complaints via the shared Google Sheet, check property/bed statuses, and coordinate with caretakers.

## Daily Workflow

### 1. View & Track Complaints (`/dashboard/maintenance`)
- Open **Maintenance** in the sidebar.
- The shared **Complaints Register** Google Sheet loads inside the PMS.
- Use the bottom spreadsheet tabs (with **Interactive Tabs** or **Preview Tabs** mode) to switch categories (Plumbing, Electrical, Carpentry, Pending, Resolved).
- If multiple sheets are configured, switch between them using the top **Sheets** tab bar.
- Click **Open in Google Sheets** to open the sheet directly in Google Drive/Sheets when editing is required.

### 2. Update Sheet Links (Maintenance & Admin Only)
- Click **Add Another Sheet** or the **Edit (✏️)** icon on any sheet tab to update the spreadsheet name or Google Drive link.
- Ensure Google Drive sharing is set to **"Anyone with the link can view"** so all staff can view it seamlessly.

### 3. Property & Caretaker Coordination
- **Caretakers** (`/dashboard/caretakers`): View caretaker names, assigned flats, and tap-to-call phone numbers.
- **Bed Inventory** (`/dashboard/beds`): Check which beds are vacant, occupied, or blocked during repairs (contact Admin to toggle a bed between `blocked` and `vacant`).
